# DIA_tools_benchmark
We compared various programm tools for analysis of DIA LFQ proteomics data in terms of differential expression detection (DIA-NN; FragPipe with MSFragger-DIA, DIA-Umpire, and diaTracer; AlphaPeptStats, directLFQ, Triqler). This repository contains all needed information, scripts and parameters to reproduce the results of our study.
